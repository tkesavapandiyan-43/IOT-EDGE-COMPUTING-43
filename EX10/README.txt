EXPERIMENT: Web User Interface LED ON/OFF using Ethernet Shield

File:
Ethernet_Web_LED_ON_OFF.txt

Hardware:
- Arduino UNO
- Ethernet Shield
- LED
- Network cable

LED Pin:
Pin 7

Default IP:
192.168.1.20

Open this address in a browser:
http://192.168.1.20

Use the LED ON and LED OFF buttons on the web page to control the LED.
